FULL PROJECT RECOVERY PROMPT

Before continuing any work:
- read AI context files
- read architecture files
- read plan files
- read recovery files
- read current implementation status
- read response format rules
- read recent AI tasks
- then reconstruct exact current project state
- detect already-implemented items to avoid duplicate/conflicting re-planning
- if the user marks constraints as mandatory, preserve them as mandatory in architecture/plan/recovery outputs
- enforce Goal Alignment gate for AI tasks using docs/plans/product_goal_traceability_matrix.md Requirement IDs
- enforce the Cursor/agent responsibility split:
  - Cursor prompt is development-only
  - planning, architecture, validation strategy, manual testing, closure gates, and response packaging stay with the agent
- include manager-facing summaries for current and next AI steps
- treat contextJSON as a frozen historical external export only, never as architecture/process authority
- do not generate new contextJSON snapshots during restore, architecture sync, task issue, or task closure
- enforce Task Closure Hard Gate Checklist before any task is marked complete
- for UI-scope tasks, require both Playwright visual validation by the agent and explicit user-side manual visual checks
- enforce docs/architecture/git-branch-workflow.md for Stage branches
- enforce docs/architecture/change-management-process.md before new functionality or functional changes

Context restore policy:
- Fast restore before each new AI task
- Full restore after:
  - `обнови архитектурные файлы`
  - merge/stage transition
  - suspected desync
  - long pause
  - explicit `обнови полный контекст`
- command mapping:
  - `обнови контекст` => Fast restore (default)
  - `обнови полный контекст` => Full restore (forced)
  - `обнови полный контест` => Full restore (forced, typo alias)

Next-task command equivalence:
- Treat `дай следующую аи таск`, `следущую аи таск`, and `следущую задачу` as equivalent to `дай следующую AI task`.
- Apply the same next-task response format gate for all equivalents.
