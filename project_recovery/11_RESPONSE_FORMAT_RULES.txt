RESPONSE FORMAT RULES — UNIVERSAL MODE 3.0

- Apply configured project prefix and lean delta-only reporting.
- Report outcome, failed/blocked fact and next action; do not repeat full logs.
- Full Restore reports state_id, actual repository facts, correction count,
  delivery/acceptance, CR-trigger coverage, budgets, blockers and readiness.
- Next-task output includes path, manager summary and one complete copyable
  implementation prompt with Outcome Slice, mappings, risk, criteria,
  exclusions, commands, automated proof and self-review.
- Implementation reports are handoff input, not canonical PASS.
- OWNER manual instructions are only for ready running UI/device functionality
  or explicit external authority actions; automatable validation stays agent-owned.
- In-scope defects use TASK-AMENDMENT; material changes use CR.
- Closure records traceability, evidence, cleanup, commit and push.
- Fast/Full/architecture/completion commands route through the trigger registry.
- No restore/sync/task/closure regenerates frozen historical context exports.
