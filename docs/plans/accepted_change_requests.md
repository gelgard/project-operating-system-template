# Accepted Change Requests

This file is the technical-specification addendum registry.

Every accepted Change Request must record:
- ID and title;
- classification and decision;
- product/specification delta;
- Requirement IDs;
- architecture, design, security, data, runtime, and plan impact;
- task placement;
- acceptance criteria;
- source-of-truth files updated.
- matching `rule_bindings` entry in the governance trigger registry with a
  unique ID, source CR, action, authorities, expected evidence and fail-closed
  result; the binding must also state the event/condition that activates it.

Accepted entries become inseparable requirements of the effective specification.
Approval alone is not propagation. Missing accepted-register entry, trigger
binding, affected source update, validation or documentation commit blocks
implementation.
