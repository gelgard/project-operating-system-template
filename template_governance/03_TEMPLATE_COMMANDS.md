# Template Commands

- обнови template-repo
- собери canonical template-repo
- обнови контекст
- обнови полный контекст
- дай следующую AI task
- необходимо внести изменения
- обнови архитектурные файлы
- таск выполнен / задача выполнена / задача готова / готово
- проверь лог (only when the created project defines a canonical persisted operational audit)

Exact aliases and automatic event triggers are defined in
`docs/architecture/governance-trigger-registry.json`. Projects may add
unambiguous aliases but may not delete universal command semantics.
