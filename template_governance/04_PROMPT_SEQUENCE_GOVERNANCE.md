# Prompt Sequence Governance

Required prompt layers:
1. Project Intake
2. Architecture Foundation
3. Plan Decomposition
4. Recovery Setup
5. Start Implementation
6. Standard Working Mode
7. Recovery In A New Chat

Each layer preserves the current-state manifest, trigger registry, Outcome
Slice/DoR model, risk-proportional validation, implementation-agent transport,
independent handoff audit, two-correction stop and archive non-authority.
