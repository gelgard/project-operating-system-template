
TEMPLATE OPERATING SYSTEM RECOVERY RULE

Recovery in a new chat must restore not only the current project state, but also the template-inherited operating system:

- architecture rules
- planning rules
- recovery rules
- response format rules
- architecture update procedure
- contextJSON rules
- command model
- engineering, lean, credential-security, and design contracts
- accepted Change Request addenda and propagation state
- task-completion aliases and automatic-commit closure behavior

The recovered project must continue inside the same inherited framework, not in a newly improvised one.
