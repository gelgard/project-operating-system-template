RECOVERY SETUP PROMPT

        Build the recovery layer inside the framework inherited from the template repository.

        Do not design recovery from scratch if the template already defines:
        - recovery files
        - architecture update procedure
        - archive-first sync workflow
        - frozen contextJSON archive rules
        - response format rules
        - command model
        - engineering/lean/credential/design contracts
        - completion aliases and automatic-commit closure behavior
        - accepted Change Request propagation audit

        Adapt the inherited recovery system to the new project's domain while preserving the template operating-system behavior.
